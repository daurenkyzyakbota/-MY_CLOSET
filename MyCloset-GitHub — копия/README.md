# MyCloset

Адаптивное веб-приложение на Next.js с Material UI и Bootstrap для личного гардероба, образов и планов на каждый день.

## Запуск

Требуется Node.js 20.9 или новее.

```sh
pnpm install
pnpm dev
```

Откройте `http://localhost:3000`.

```sh
pnpm build
pnpm start
pnpm test
```

## Интерфейс

Material UI используется для кнопки добавления вещей, уведомлений об ошибках и темы приложения. Bootstrap подключён как адаптивная сеточная основа. Оба набора стилей загружаются до фирменных стилей MyCloset.

## Возможности

- Гардероб с фотографиями, цветами, сезонами, категориями, брендом, размером, материалом и заметками.
- Поиск, фильтры, сортировка, избранное и отметка вещей в стирке.
- Подбор до трёх образов по поводу, стилю, сезону и выбранной вещи.
- Прогноз Open-Meteo, выбор города и ручная погода, если прогноз недоступен.
- Ручная сборка, сохранение и копирование образов, планы на день и вечер.
- Список покупок с фильтрами и ссылками на поиск похожих вещей в Kaspi.kz и Lamoda.kz.
- Экспорт и импорт резервных копий версий 1–4, QR-ссылка, установка как PWA и офлайн-оболочка.

Подбор образов работает по правилам; внешний ИИ не используется. Цены и наличие товаров не выдумываются.

## Данные и приватность

Вещи, фотографии, профиль, образы, покупки и планы хранятся в IndexedDB браузера под именем `mycloset-local-v1`. Данные остаются на устройстве и не синхронизируются автоматически. Для переноса между устройствами используйте резервную копию в настройках.

Прогноз и поиск города запрашиваются через Next.js Route Handlers `/api/weather` и `/api/cities`. Сервер обращается только к фиксированным HTTPS-адресам Open-Meteo. Пользовательские данные гардероба на сервер не отправляются.

## Структура

| Путь | Назначение |
| --- | --- |
| `app/` | Next.js App Router, страница и API Route Handlers |
| `public/` | Клиентский интерфейс, стили, изображения, шрифты, PWA и офлайн-оболочка |
| `model.mjs` | Формат данных, IndexedDB-миграции, фильтры и проверки резервных копий |
| `stylist.mjs`, `shopping.mjs` | Подбор образов, недостающие вещи и ссылки магазинов |
| `weather.mjs` | Проверка данных и интеграция Open-Meteo |
| `platform.mjs`, `qrcode.mjs` | Установка PWA, статус соединения и QR-код |
| `tests/` | Проверки данных, миграций, стилиста, покупок и офлайн-поведения |
| `README_MyCloset.md` | Исходное техническое задание проекта |

`index.html` и `dev-server.mjs` оставлены как исходные файлы прежнего статического запуска. Команды разработки и сборки теперь используют Next.js.

## Лицензии

QR-библиотека сохраняет уведомление MIT в `qrcode.mjs`. Лицензии Manrope и Cormorant Garamond находятся в `assets/fonts/`.
