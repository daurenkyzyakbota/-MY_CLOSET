# MyCloset Bota

**[Открыть сайт](https://mycloset-bota-wardrobe.rockynewt20.chatgpt.site/)**

Виртуальный гардероб для компьютера и телефона. Опубликованная версия открывается по ссылке без CMD, включённого компьютера и аккаунта GPT. Её можно добавить на главный экран устройства.

## Что работает

- Гардероб с фотографиями, категориями, типом вещи, цветами, сезонами, размером, брендом, материалом, заметками и датой покупки.
- Поиск, фильтры, сортировка, избранное и исключение вещей в стирке.
- Подбор до трёх образов по правилам: повод, стиль, цвета, сезон, выбранная вещь и погода.
- Настоящий прогноз Open-Meteo, выбор города и ручной ввод погоды при недоступном интернете.
- Ручные и предложенные образы, отдельные недостающие детали, замена своей одеждой, копирование и календарь на день и вечер.
- Список покупок с личным бюджетом и поиском похожих вещей в Kaspi.kz и Lamoda.kz. Цены и наличие сайт не выдумывает.
- Экспорт и импорт гардероба, QR-код ссылки, установка как веб-приложения и офлайн-оболочка после первого открытия.

## Данные

Гардероб и фотографии сохраняются в IndexedDB этого браузера. У другого посетителя свой гардероб. Автоматической синхронизации между устройствами пока нет; перенос выполняется через резервную копию в настройках. Поддерживается импорт копий версий 1–4.

Подбор работает по правилам, без внешнего ИИ. Интернет нужен для первого открытия, актуального прогноза и перехода в магазины.

## Локальная разработка

Нужен Node.js 20 или новее. Внешних зависимостей и сборки нет, `npm install` не требуется.

```sh
npm run dev
```

Откройте `http://127.0.0.1:4173`. Завершение локального просмотра — Ctrl+C. Это режим разработки; пользователям достаточно опубликованной ссылки выше.

```sh
npm test
```

Проверки охватывают миграции данных, валидацию резервных копий, подбор, покупки, новые поля одежды, офлайн-оболочку, QR-код и переносимость ссылок.

## Структура

| Файлы | Назначение |
| --- | --- |
| `index.html`, `styles.css`, `app.mjs` | Интерфейс и действия пользователя |
| `model.mjs` | Данные, фильтры и миграции формата |
| `stylist.mjs`, `shopping.mjs` | Подбор образов и недостающих вещей |
| `weather.mjs` | Проверка и загрузка погоды из Open-Meteo |
| `platform.mjs`, `qrcode.mjs` | Ссылки, QR-код и установка |
| `manifest.webmanifest`, `sw.js` | Веб-приложение и офлайн-кэш |
| `assets/` | Изображение, значки, шрифты и лицензии |
| `dev-server.mjs` | Локальный просмотр без зависимостей |
| `tests/` | Проверки данных и логики |
| `README_MyCloset.md` | Сохранённое исходное техническое задание |

Для размещения подойдёт HTTPS-хостинг статических файлов. Публикуемые файлы находятся в корне и `assets/`; служебный сервер и тесты нужны для разработки. Обновление этого GitHub-репозитория само по себе не перепубликовывает существующий сайт.

## История и исходное ТЗ

Существующие коммиты сохранены. Неиспользуемая заготовка Next.js и старая вложенная копия сайта заменены текущими исходниками. Исходное ТЗ сохранено без изменений как план развития: указанные в нём Next.js, аккаунты, серверная база и внешний ИИ не описывают уже реализованную архитектуру этой версии.

## Использованные ресурсы

Погодные данные — [Open-Meteo](https://open-meteo.com/). QR-библиотека — [Project Nayuki](https://www.nayuki.io/page/qr-code-generator-library), лицензия MIT включена в `qrcode.mjs`. Лицензии шрифтов находятся в `assets/fonts/OFL-Manrope.txt` и `assets/fonts/OFL-Cormorant-Garamond.txt`.
