# MyCloset — Виртуальный гардероб

## 1. Описание проекта

**MyCloset** — учебный проект веб-приложения для организации личного гардероба и создания стильных образов.

Пользователь сможет добавлять вещи, распределять их по категориям, составлять комплекты и планировать наряды. На текущем этапе создана базовая структура Next.js; перечисленные ниже возможности являются **планируемыми функциями**.

## 2. Цель проекта

Разработать удобное и адаптивное веб-приложение на Next.js для управления личным гардеробом.

## 3. Техническое задание

### Планируемые функции

1. **Мой гардероб:** добавление вещей с фотографиями, указание названия, цвета и категории; просмотр, редактирование и удаление вещей.
2. **Категории:** верхняя одежда, футболки и топы, брюки и джинсы, платья и юбки, обувь, аксессуары.
3. **Создание образов:** выбор нескольких вещей, создание комплекта, сохранение образа.
4. **Избранное:** добавление любимых образов и быстрый просмотр.
5. **Календарь нарядов:** выбор даты и назначение образа на конкретный день.

## 4. Страницы приложения

| Страница | Назначение |
|---|---|
| Главная | Приветствие и обзор гардероба |
| Мой гардероб | Просмотр и добавление одежды |
| Создать образ | Комбинирование вещей |
| Мои образы | Просмотр сохранённых комплектов |
| Календарь | Планирование нарядов |
| Избранное | Любимые образы |

## 5. Дизайн приложения

**Стиль:** современный минимализм, светлый и эстетичный интерфейс.

**Цветовая палитра:**
- Нежно-розовый — `#F8DDE5`
- Кремовый — `#FFF8F0`
- Бежевый — `#EADBC8`
- Тёмно-коричневый — `#493B35`
- Белый — `#FFFFFF`

**Особенности интерфейса:** карточки одежды с фотографиями, закруглённые кнопки, понятная навигация и адаптация для мобильных устройств.

## 6. Используемые технологии

- **Next.js** — фреймворк для веб-приложений.
- **React** — создание компонентов интерфейса.
- **TypeScript** — разработка с проверкой типов.
- **Tailwind CSS** — стилизация страниц.
- **Node.js и npm** — среда выполнения и управление пакетами.
- **Git и GitHub** — управление версиями и хранение проекта.

## 7. Этапы разработки

1. Создание репозитория GitHub.
2. Установка и запуск Next.js.
3. Описание проекта и технического задания.
4. Создание главной страницы.
5. Реализация гардероба и категорий.
6. Разработка конструктора образов.
7. Добавление избранного и календаря.
8. Проверка приложения и публикация новых версий.

**Текущий статус:** выполнены этапы 1–3; основной функционал запланирован для следующих этапов.

## 8. Команды и их назначение

| Команда | Назначение |
|---|---|
| `node -v` | Проверить версию Node.js |
| `npm.cmd -v` | Проверить версию npm в PowerShell |
| `npx.cmd create-next-app@latest .` | Создать Next.js-проект в текущей папке |
| `npm.cmd run dev` | Запустить сервер разработки |
| `npm.cmd run build` | Создать производственную сборку приложения |
| `git status` | Посмотреть состояние файлов Git |
| `git add README.md` | Подготовить README.md к коммиту |
| `git commit -m "Сообщение"` | Зафиксировать подготовленные изменения |
| `git push` | Отправить локальные коммиты в GitHub |

## 9. Запуск проекта

В папке проекта установите зависимости (если ещё не установлены):

```powershell
npm.cmd install
```

Запустите сервер разработки:

```powershell
npm.cmd run dev
```

Откройте в браузере: http://localhost:3000
