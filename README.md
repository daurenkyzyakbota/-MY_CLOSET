# MyCloset — Виртуальный гардероб

## 1. Описание проекта

**MyCloset** — учебный проект веб-приложения для организации личного гардероба и создания стильных образов.

Пользователь сможет добавлять вещи, распределять их по категориям, составлять комплекты и планировать наряды. На текущем этапе создана базовая структура Next.js; перечисленные ниже возможности являются **планируемыми функциями**.

## 2. Цель проекта

Разработать удобное и адаптивное веб-приложение на Next.js для управления личным гардеробом.

## 3. Техническое задание

### Планируемые функции

1. **Мой гардероб:** добавление вещей с фотографиями, указание названия, цвета и категории; просмотр, редактирование и удаление вещей.
2. **Категории:** верхняя одежда, футболки и топы, брюки и джинсы, платья и юбки, обувь, аксессуары.
3. **Создание образов:** выбор нескольких вещей, создание комплекта, сохранение образа.
4. **Избранное:** добавление любимых образов и быстрый просмотр.
5. **Календарь нарядов:** выбор даты и назначение образа на конкретный день.

## 4. Страницы приложения

| Страница | Назначение |
|---|---|
| Главная | Приветствие и обзор гардероба |
| Мой гардероб | Просмотр и добавление одежды |
| Создать образ | Комбинирование вещей |
| Мои образы | Просмотр сохранённых комплектов |
| Календарь | Планирование нарядов |
| Избранное | Любимые образы |
