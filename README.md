# Next.js Practice

## 1. Описание проекта

Next.js Practice — учебный проект, разработанный с использованием фреймворка Next.js.

Цель работы — изучить создание веб-приложений, использование команд терминала и работу с GitHub.

## 2. Техническое задание (ТЗ)

**Название:** Next.js Practice

**Цель:** Создать и запустить веб-приложение Next.js, а также разместить проект в GitHub.

**Задачи:**
1. Создать новый репозиторий на GitHub.
2. Установить Next.js.
3. Создать структуру веб-приложения.
4. Запустить локальный сервер разработки.
5. Проверить работу приложения в браузере.
6. Создать документацию README.md.
7. Загрузить проект в GitHub.

## 3. Используемые технологии

- Next.js — фреймворк для создания веб-приложений.
- React — библиотека для разработки интерфейсов.
- Node.js — среда выполнения JavaScript.
- npm — менеджер пакетов.
- Git — система контроля версий.
- GitHub — платформа для хранения кода.

## 4. Описание команд

| Команда | Назначение |
|---|---|
| `node -v` | Проверка версии Node.js |
| `npm.cmd -v` | Проверка версии npm |
| `npx.cmd create-next-app@latest .` | Создание проекта Next.js |
| `npm.cmd run dev` | Запуск локального сервера |
| `npm.cmd run build` | Сборка приложения |
| `git init` | Создание локального Git-репозитория |
| `git add .` | Добавление файлов в индекс Git |
| `git commit -m "Initial commit"` | Сохранение изменений |
| `git branch -M main` | Установка основной ветки main |
| `git remote add origin URL` | Подключение удалённого репозитория |
| `git push -u origin main` | Загрузка проекта на GitHub |

## 5. Запуск проекта

Для запуска приложения необходимо выполнить команду:

`npm.cmd run dev`

После этого открыть браузер по адресу:

http://localhost:3000

## 6. Ожидаемый результат

В результате выполнения практической работы должно быть создано работающее веб-приложение Next.js с документацией README.md. Исходный код проекта должен быть опубликован в репозитории GitHub.

## 7. Вывод

В ходе практической работы был изучен процесс создания проекта на Next.js. Освоены основные команды Node.js, npm и Git. Получены практические навыки работы с GitHub и создания документации README.md.
