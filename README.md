# MyCloset

Виртуальный гардероб на **Next.js App Router и React**. В одном проекте находятся страницы сайта, компоненты, логика работы с гардеробом и серверные маршруты погоды.

Сохранены прежние дизайн и расположение разделов MyCloset: тёмное боковое меню, исходные блоки главной страницы и шесть пунктов мобильной навигации. Профиль находится в настройках. Все страницы и формы реализованы React-компонентами в Next.js.

## Запуск

Нужны Node.js 24 и npm. Откройте терминал в этой папке:

```powershell
npm.cmd install
npm.cmd run dev
```

Откройте http://localhost:3000. Телефон должен быть подключён к тому же Wi-Fi; адрес и QR-код находятся в разделе «На устройствах».

Для производственного запуска:

```powershell
npm.cmd run build
npm.cmd start
```

Сервер Next.js должен работать, пока открыт сайт. Постоянная интернет-ссылка требует хостинга с поддержкой Next.js.

## Структура как в ServiceDesk

```text
app/
  layout.jsx                  Общий документ и локальные шрифты
  globals.css                 Оформление и адаптация к телефону
  (closet)/                   Страницы с общей навигацией
    layout.jsx
    page.jsx                  Главная
    wardrobe/page.jsx         Гардероб
    outfits/page.jsx          Сохранённые образы
    outfits/create/page.jsx   Конструктор образа
    stylist/page.jsx          Подбор сочетаний
    calendar/page.jsx         Календарь
    shopping-list/page.jsx    Покупки
    favorites/page.jsx        Избранное
    profile/page.jsx          Переход в настройки со старой ссылки
    settings/page.jsx         Настройки и резервные копии
    devices/page.jsx          Подключение телефона
  manifest.js                 Настройки значка приложения для браузера
  api/
    cities/route.js           Поиск города
    weather/route.js          Настоящий прогноз Open-Meteo
    device/route.js           Адреса для подключения по Wi-Fi
components/                   React-компоненты страниц и форм
lib/                          Проверка данных, хранение и правила подбора
public/assets/                Картинки, значки, шрифты и их лицензии
tests/                        Автоматические проверки
docs/                         Техническое задание и описание устройства
next.config.mjs               Настройки Next.js
package.json                  Зависимости и команды
package-lock.json             Точные версии зависимостей
```

Как в ServiceDesk, `app` отвечает за маршруты, `components` — за интерфейс, `lib` — за логику, а `tests` и `docs` содержат проверки и документацию. Группа `(closet)` объединяет страницы под одной навигацией; её название не входит в URL.

## Что работает

- Вещи: фото, цвета, сезоны, подкатегории, размер, бренд, материал, заметки, дата покупки, теплота и защита от дождя; редактирование, удаление, избранное и стирка.
- Поиск, фильтры и сортировка гардероба.
- Ручной конструктор образов, копирование, избранное и недостающие детали.
- Стилист по правилам: повод, стиль, сезон, любимая вещь, автоматическая или ручная погода. Он использует доступные вещи и объясняет ограничения; внешнего ИИ для анализа фото нет.
- Список покупок с поиском, фильтрами, сортировкой, личным бюджетом и поисковыми ссылками в магазины. Купленную вещь можно перенести в гардероб.
- Календарь с отдельным дневным и вечерним образом, редактированием и удалением планов.
- Профиль, поиск города, экспорт и импорт резервных копий версий 1–4.
- Адаптивный интерфейс от 320 px и QR-код подключения телефона.

## Где хранятся данные

Гардероб хранится в **IndexedDB этого браузера**: база `mycloset-local-v1`, хранилище `data`, ключ `state`. Формат резервной копии — версия 4; прежние версии 1–3 преобразуются с проверкой данных. Демонстрационные вещи появляются только после нажатия «Попробовать на примере» или «Добавить примеры».

Данные разных браузеров, устройств и адресов сайта независимы. Для переноса скачайте копию в настройках, затем загрузите её на другом устройстве. Импорт заменяет текущий гардероб только после подтверждения. Очистка данных браузера удаляет локальный гардероб.

Если браузер запретил сохранение, приложение показывает предупреждение о временном сеансе. Фотографии уменьшаются перед сохранением. Для погоды и поиска в магазинах нужен интернет.

## Лицензии ресурсов

QR-алгоритм Project Nayuki распространяется по MIT; уведомление сохранено в `lib/qrcode.js`. Лицензии OFL на Manrope и Cormorant Garamond находятся рядом со шрифтами в `public/assets/fonts`.
