# Как связаны файлы

Посетитель открывает адрес страницы. Next.js находит соответствующий `app/(closet)/.../page.jsx`, подключает общий `layout.jsx` и показывает React-компонент из `components`.

Внешний вид, порядок меню и расположение основных блоков восстановлены по прежней версии MyCloset. Личный профиль снова расположен на странице настроек; `/profile` перенаправляет на `/settings`.

Например, адрес `/wardrobe` связан с `app/(closet)/wardrobe/page.jsx`. Эта страница использует `components/wardrobe-page.jsx`. Карточки вещей и формы вынесены в собственные компоненты, чтобы использовать их в гардеробе, избранном и на главной.

## Общие части

- `components/mycloset-shell.jsx` — боковое меню, верхняя панель, мобильная навигация и добавление вещи.
- `components/closet-provider.jsx` — общее состояние и действия с данными. Провайдер остаётся на месте при переходах между страницами.
- `components/ui.jsx` — общие кнопочные значки, диалоги, заголовки, поля и иллюстрации вещей.
- `app/globals.css` — цвета, типографика, карточки, формы и адаптивная сетка.

## Данные и проверки

- `lib/model.js` — формат данных, категории, миграции резервных копий и строгая проверка.
- `lib/storage.js` — чтение и запись IndexedDB, обработка ошибок и удаление старого кэша MyCloset.
- `lib/closet-state.js` — последовательное выполнение изменений. Интерфейс получает новые данные после успешной записи. Добавление купленной вещи и связь с покупкой сохраняются вместе.
- `lib/photos.js` — проверка типа и размера фотографии, уменьшение перед хранением.
- `lib/stylist.js` — правила подбора комплектов из доступных вещей.
- `lib/shopping.js` — недостающие детали и фиксированные поисковые ссылки магазинов.
- `lib/shopping-filters.js` — поиск и сортировка покупок, включая бюджет `0` и неуказанный бюджет.
- `lib/outfit-weather.js` — погодные условия для конкретной даты и ручного ввода.

## Погода

Браузер обращается к `/api/cities` и `/api/weather`. Next.js проверяет параметры, запрашивает фиксированные HTTPS-адреса Open-Meteo и возвращает нормализованные данные. Отсутствующий или недоступный прогноз отображается явно; для далёкой даты можно задать условия вручную.

`lib/weather-service.js` создаёт серверный сервис, `lib/weather.js` проверяет ответы, ограничивает размеры данных и частоту запросов, а `lib/weather-client.js` выполняет запросы из браузера.

## Сходство с ServiceDesk

Оба проекта используют Next.js App Router, JavaScript/JSX, группы маршрутов, отдельные React-компоненты и папки `lib`, `tests`, `docs`. У MyCloset есть `public/assets` для изображений и локальных шрифтов. Данные текущей версии MyCloset сохраняются в браузере, поэтому отдельная серверная база для запуска не нужна.
