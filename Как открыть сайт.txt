БЫСТРЫЙ ЗАПУСК MYCLOSET

ЧЕРЕЗ ИНТЕРНЕТ — ОСНОВНОЙ СПОСОБ

Дважды нажмите «Мой гардероб онлайн.url» в этой папке.
Адрес: https://mycloset-wardrobe-6c42.nurgazydauren512.chatgpt.site
Этот адрес можно открыть на другом компьютере или телефоне из любой сети.
Домашний компьютер при этом может быть выключен.

Войдите с той же почтой и паролем MyCloset. На первом устройстве нажмите
«Сохранять гардероб в аккаунте», на новом — «Открыть мой гардероб».
После подключения вещи, фотографии, образы, покупки, календарь, история,
капсулы, поездки и личные настройки сохраняются автоматически.
Статус в шапке показывает, завершилось ли сохранение в аккаунте.
Размер облачной копии с фотографиями — до 12 МиБ. Полную JSON-копию можно
скачать в настройках; большие копии можно открыть в локальной версии.
Имя и профиль редактируются в разделе «Аккаунт».
Гостевые вещи переносятся отдельной кнопкой с подтверждением.

ЛОКАЛЬНЫЙ ЗАПУСК — РЕЗЕРВНЫЙ СПОСОБ

1. Дважды нажмите «Открыть MyCloset.cmd» в этой папке.
2. Подождите запуска: сайт откроется в вашем обычном браузере.
3. При повторном открытии файл использует уже работающий сервер этой папки.

Если Node.js ещё не установлен, установите версию 24 с https://nodejs.org/.
Первый запуск без папки node_modules установит зависимости; для этого нужен интернет.
Не переносите файл запуска отдельно от остальной папки проекта.

Обычно сайт открывается по адресу http://localhost:3000.
Если порт занят другой программой, запуск выберет свободный и запомнит его.
Разные адреса и порты имеют разные локальные данные браузера: при смене адреса
используйте резервную JSON-копию или явно подключённую синхронизацию аккаунта.
Существующие гардеробы автоматически не переносятся и не удаляются.

Это локальный сайт на данном компьютере. После закрытия браузера сервер продолжает
работать в фоне; после выключения или перезагрузки компьютера нажмите файл снова.
Чтобы открыть сайт, компьютер и локальный сервер должны работать.
Исходники подхватываются при следующем обращении к странице; старая готовая сборка
для запуска не используется.

Адрес localhost на другом компьютере означает тот другой компьютер.
Для доступа через интернет используйте опубликованную HTTPS-ссылку выше.
Другой вариант — запустить полную копию проекта на втором компьютере, отдельно
настроить серверные переменные .env.local для облака и войти в свой аккаунт.
Для переноса вещей включите синхронизацию явно либо импортируйте резервную копию.
Обычная HTTP-ссылка по локальной сети не заменяет публичный сайт и не подходит
для защищённого входа в аккаунт с другого устройства.

Если запуск не удался, окно покажет причину и путь к журналам в .local.
Эта папка не попадает в Git. Не публикуйте .env.local, журналы и резервные копии.

Для проверки без открытия браузера:
  powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-local.ps1 -NoBrowser

Для выбора порта:
  powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-local.ps1 -Port 3006
